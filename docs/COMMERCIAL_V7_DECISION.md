# AION Service CRM Commercial v7 — Owner-approved visual target

Date: 2026-08-02

Status: OWNER APPROVED VISUAL TARGET / INTERACTIVE DEMO IMPLEMENTED / NOT PRODUCT-INTEGRATED

## Canonical direction

- premium dark AION shell with restrained blue-violet glow;
- one consistent 3D icon language across Home, Orders, Repair, Clients and More;
- compact brand header with RU/EN, theme and settings;
- Home priority: Work zone + EvE, metrics, New repair, Find order, Handover, Price and ETA, QR, Model by photo, Work queue;
- Handover icon represents a smartphone, not a parcel;
- New repair uses a rear smartphone plus badge, not an emergency/medical symbol;
- Work queue uses rear device views because technicians identify models from the back and camera layout;
- Current Order is removed from Home and remains inside deeper repair/order workspaces;
- bottom navigation uses the same rectangular premium 3D language; Home is active on Home.

## Product boundaries

The prototype demonstrates layout and interaction only. Real authentication, database, QR decoding reliability, image recognition, supplier APIs, stock, ETA, payment, legal documents, QC and issuance enforcement are not implemented here.

## Rollback

Commercial v6.1 remains available as a reversible previous prototype.
