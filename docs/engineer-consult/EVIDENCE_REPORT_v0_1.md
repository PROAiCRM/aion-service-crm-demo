# EVE Техконсультант — Evidence Report v0.1

**Дата:** 2026-08-02  
**Уровень:** интерактивный демонстрационный прототип и production RFC  
**Реальные технические консультации:** не тестировались

## Реализовано в публичном прототипе

- карточка демонстрационного ремонта;
- скрытая кнопка «Спросить инженера»;
- автоматический контекст заказа;
- быстрые технические вопросы;
- консультационный drawer;
- структурированный ответ;
- confidence, риски и недостающие данные;
- список типов источников;
- действия сохранить, создать чек-лист и эскалировать.

## Проверки

- JavaScript прошёл `node --check`;
- HTML, CSS и JS опубликованы отдельными файлами на `main`;
- существующий канонический CRM entry point не заменён;
- production-контракт создан в приватном репозитории как draft PR №200.

## Ограничения

- ответы в прототипе детерминированные и демонстрируют формат, а не реальную инженерную экспертизу;
- внешняя AI-модель не подключена;
- официальные руководства, технические базы и интернет-источники не подключены;
- реальные клиентские данные не использовались;
- браузерная screenshot-проверка из рабочей среды не завершилась из-за блокировки/таймаута Chromium;
- полезность, точность, безопасность и коммерческий эффект ещё не доказаны.

## Следующее доказательство

Owner acceptance на телефоне:

1. открыть прототип;
2. задать три разных вопроса;
3. оценить понятность структуры ответа;
4. проверить, не выглядит ли ответ слишком уверенно;
5. подтвердить входные точки внутри диагностики, выбора детали, ОТК и выдачи.
