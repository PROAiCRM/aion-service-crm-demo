# EVE Техконсультант — Risk Register v0.1

| ID | Риск | Критичность | Контроль |
|---|---|---:|---|
| EC-R01 | Уверенный, но ошибочный технический ответ | Критическая | источники, confidence, недостающие данные, эскалация |
| EC-R02 | Мастер выполняет совет без измерений | Высокая | маршрут проверок, стоп-условия, Action Receipt |
| EC-R03 | Устаревшие сведения о модели или детали | Высокая | дата источника, freshness policy, запрет ответа при недостаточной свежести |
| EC-R04 | Непроверенные отзывы принимаются за факт | Высокая | отзывы только как слабый сигнал, разделение типов источников |
| EC-R05 | Передача клиентских секретов внешней модели | Критическая | D0–D4 классификация, redaction, default-deny |
| EC-R06 | Опасная работа с аккумулятором, платой или жидкостью | Критическая | hazard policy, СИЗ, stop/escalate, запрет автономных действий |
| EC-R07 | Внутренняя база накапливает неверные советы | Высокая | верификация старшим инженером, версия и отзыв знания |
| EC-R08 | Ассистент заменяет обучение мастера | Средняя | объяснение причин и проверок, а не только ответ |
| EC-R09 | Нет доказуемой пользы | Средняя | метрики времени, возвратов, first-time-fix и эскалаций |
