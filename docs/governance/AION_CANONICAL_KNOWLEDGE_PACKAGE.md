## Purpose

Create one governed knowledge base for AION in GitHub. This package does not claim that all historical project knowledge has already been migrated. It establishes the canonical structure, precedence rules, maturity language, and migration boundary.

## Source-of-truth rule

GitHub is the technical source of truth after a document is reviewed and merged into the default branch. Chat history, local files, PDFs, screenshots and earlier packages remain evidence or migration sources until registered here.

## Precedence

1. Accepted constitutional and BOOT principles.
2. Accepted ADRs and policies.
3. Current State and Decision Log.
4. Approved product and UX canon.
5. RFCs and designed solutions.
6. Prototypes and evidence artifacts.
7. Historical or archived material.

A newer file does not automatically override an accepted decision. Supersession must be explicit.

## Maturity vocabulary

- IDEA
- HYPOTHESIS
- PROPOSAL
- DESIGNED
- PROTOTYPED
- IMPLEMENTED
- TESTED
- COMMERCIALLY PROVEN

No item may be promoted without matching evidence.

## Safe cleanup policy

Outdated and conflicting material is not deleted by default. It is marked `DEPRECATED`, `SUPERSEDED` or `ARCHIVED`, linked to its replacement and removed from active navigation.

## Current migration status

The public demo repository currently contains product demonstration assets and does not yet contain the complete historic AION governance corpus. This set creates the receiving structure. Full consolidation remains incomplete until source documents are imported, compared and individually classified.
